# Yasin Cengiz

Two decades building enterprise software, now mostly building agentic systems. Most of what's behind this graph is private.

What it is, mostly: the unglamorous engineering that makes agents survive contact with production. Graded evaluation harnesses with committed regression baselines. Bounded retries instead of infinite ones. Idempotent stages, so a crashed or budget-stopped run resumes without re-spending. Deterministic rendering where reproducibility matters more than variety.

Recent builds include a real-time voice agent on OpenAI's Realtime API where audio never touches my server, a multi-channel agent platform serving chat, SMS, WhatsApp and voice from one service, and an agentic production pipeline whose manifest is its state machine.

I write about this at [yasincengiz.com](https://yasincengiz.com) and on [LinkedIn](https://www.linkedin.com/in/yasincengiz/).
